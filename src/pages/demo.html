How well the checks work

    
Every test letter, checked on this page by the same code the service uses. A letter counts as correct if its type is recognised, the outcome matches, and a rejected letter fails for the reason it was rejected.

    

    
The hackathon pack has 12 real-style examples, covering 5 types of letter. The other letters are variations and fictional examples written for this prototype, so these results show the rules are consistent – not that they match Legal Aid Agency decisions. Measuring that needs a larger set of real, anonymised decisions.

    

      !
      WarningThe rules were written from these letters, so they get them all right. On 13 letters in different wording from a separate review pack, they got 0 right: they look for the wording in the guidance and miss letters that say the same thing another way. A person should always check the result. See how the checks work and every result.
    

  


  

    
Rules compared with an AI model

    
The letter checker can also ask a small AI model (DeBERTa v3, run in the browser) whether key sentences sound uncertain. We measured both on 45 test letters.

    

      
MethodUncertain letters foundFirm letters wrongly flagged

      
        
Rules16 of 160 of 29

        
AI model11 of 160 of 29

      
    

    
The rules were written from these letters, so they are expected to do well on them. The model has never seen them, which makes it a useful independent check on letters the rules were not written for. The model is optional and only runs if the person agrees.
